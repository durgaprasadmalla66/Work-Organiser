# Work-Organiser
Here is what CutDesk actually does:
Feature	How it helps an editor
Project tracking	Stores client details, deliverables, deadlines, and scope
Status tracking	Moves work through Brief, Editing, Review, and Delivered
Revision tracking	Logs feedback rounds and compares them with the agreed limit
Extra revision charges	Adds the agreed charge when included rounds are exceeded
Payment records	Tracks advances, final payments, and remaining balances
Dashboard	Shows active projects, received payments, outstanding balances, and overdue projects
Invoices	Prepares a printable invoice; the browser can save it as PDF
Payment reminders	Creates a message the editor can copy and send
Backups and exports	JSON preserves full records; CSV exports a project summary


For example: an editor charges ₹2,000, includes two revision rounds, and agrees on ₹300 per extra round. After three rounds, CutDesk calculates ₹2,300 total. If ₹1,000 was received, it shows ₹1,300 remaining.
